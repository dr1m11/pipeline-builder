# Design tokens

Components never use raw colours. They use Tailwind utilities generated from CSS variables in
`src/app/styles/tokens.css`, so both themes come from one place. Switch the theme in the toolbar to
compare.

## Usage

| Token     | Utilities                                              |
| --------- | ------------------------------------------------------ |
| `canvas`  | `bg-canvas`                                            |
| `surface` | `bg-surface`, `bg-surface-muted`                       |
| `fg`      | `text-fg`, `text-fg-muted`                             |
| `border`  | `border-border`                                        |
| `accent`  | `bg-accent`, `hover:bg-accent-hover`, `text-accent-fg` |
| `danger`  | `bg-danger`, `text-danger-fg`                          |
| `focus`   | `outline-focus`, `ring-focus`                          |

Adding a colour means adding a variable for both themes in `tokens.css` and mapping it in the
`@theme inline` block of `index.css`.
